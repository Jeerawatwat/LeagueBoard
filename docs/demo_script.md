# ขั้นตอนเดโม LeagueBoard

ใช้เวลาประมาณ 10 นาที รหัสผ่านอยู่ใน `README.md`

## เตรียมก่อนเดโม

- เปิดเว็บด้วย `npm start` แล้วเปิด http://localhost:3000
- โหมด mock: รัน `npm run mock:reset` ก่อนเพื่อคืนข้อมูลเริ่มต้น
- โหมด mssql: รัน `database/08_sample_data.sql` ใหม่บนฐานข้อมูลที่ล้างแล้ว และเปิด SSMS ไว้ที่ `ScoreAuditLog`
- เปิดเบราว์เซอร์สองหน้าต่าง หน้าหนึ่งค้างที่ตารางคะแนน อีกหน้าหนึ่งใช้ login

## 1. ตารางคะแนน

1. เปิด `/standings`
2. ชี้อันดับ แต้ม ผล 5 นัดล่าสุด และแถบสีโซนด้านซ้าย
3. เปลี่ยน dropdown เป็นฤดูกาล 2025 แล้วเปลี่ยนกลับ
4. จำแต้มของสองทีมในแมตช์ที่จะกรอกผล

**สิ่งที่แสดง:** `vw_LeagueTable`, `RANK()`, `fn_TeamForm`, `SeasonZones`

## 2. Referee กรอกผล

1. login `referee` แล้วไปที่ **กรอกผล**
2. เลือกแมตช์แรกใน "รอกรอกผล"
3. กรอก 2–1 แล้วกด **บันทึกผล**
4. เพิ่มเหตุการณ์ประตูสองครั้งให้ทีมเหย้าและหนึ่งครั้งให้ทีมเยือน

**สิ่งที่แสดง:** `usp_RecordMatchResult` (TRANSACTION + TRY/CATCH), `usp_AddMatchEvent`

## 3. ตารางคะแนนเปลี่ยน

1. รีเฟรชหน้าตารางคะแนน ทีมเหย้าได้เพิ่ม 3 แต้ม
2. เปิดหน้าแรก เห็นผลล่าสุดและการแจ้งเตือนใหม่
3. เปิด `/top-scorers` ประตูเพิ่มขึ้น

**สิ่งที่แสดง:** `trg_Matches_UpdateStandings`, `fn_CalcPoints`, `Notifications`, `vw_TopScorers`

## 4. แก้สกอร์ย้อนหลัง

1. กลับไปหน้ากรอกผลของแมตช์เดิม
2. แก้เป็น 1–1 แล้วบันทึก
3. หน้าจอเตือนว่าจำนวนประตูไม่ตรงสกอร์
4. รีเฟรชตารางคะแนน แต้มคำนวณใหม่ถูกต้อง ไม่บวกซ้อน ทีมเหย้าลดเหลือเพิ่ม 1 แต้ม

**สิ่งที่แสดง:** การคำนวณใหม่ทั้งฤดูกาล

## 5. ดู audit log

1. logout แล้ว login `admin`
2. ไปที่ **ผู้ดูแล** → **ประวัติการแก้สกอร์**
3. แถวบนสุดแสดงสกอร์เดิม 2–1 สกอร์ใหม่ 1–1 ผู้แก้ `referee` และเวลา

**สิ่งที่แสดง:** `trg_Matches_AuditScore`, `vw_ScoreAudit`

## 6. กรอกข้อมูลผิดแล้วถูกปฏิเสธ

login `referee` แล้วลองในหน้ากรอกผล

| ลอง | ผล |
|---|---|
| กรอกสกอร์ -1 | สกอร์ต้องเป็นจำนวนเต็มตั้งแต่ 0 ขึ้นไป |
| เพิ่มเหตุการณ์นาทีที่ 130 | นาทีต้องอยู่ระหว่าง 0–120 |
| แมตช์ที่ยังไม่มีผล แล้วเพิ่มเหตุการณ์ | ต้องบันทึกผลการแข่งขันก่อนเพิ่มเหตุการณ์ |

login `manager` แล้วไปที่ **ทีมของฉัน** → **นักกีฬา**

| ลอง | ผล |
|---|---|
| เพิ่มเบอร์ 100 | เบอร์เสื้อต้องอยู่ระหว่าง 1–99 |
| เพิ่มเบอร์ที่มีคนใช้แล้ว | เบอร์เสื้อนี้มีผู้เล่นในทีมใช้แล้ว |

**แมตช์แก้พร้อมกัน:** เปิดหน้ากรอกผลของแมตช์เดียวกันสองแท็บ บันทึกแท็บแรก แล้วบันทึกแท็บที่สอง จะได้ "มีผู้อื่นแก้ไขแมตช์นี้ไปแล้ว"

**สิ่งที่แสดง:** CHECK, UNIQUE, Rule, ROWVERSION และการแปลง error เป็นภาษาไทย

## 7. Viewer ลองแก้แล้ว Permission denied

ผู้ชมที่ยังไม่ login ไม่มีบัญชีใน `Users` การทดสอบนี้จึงเรียก SP ผ่าน connection ของ `lb_viewer` โดยตรง

1. login `admin` แล้วเปิด **ตรวจฐานข้อมูล** (`/db-check`)
2. กด **ลองแก้ผลในฐานะ viewer**
3. หน้าจอขึ้น "คุณไม่มีสิทธิ์ทำรายการนี้ (Permission denied)"

โหมด mssql แสดงเพิ่มใน SSMS: login ด้วย `lb_viewer` แล้วลอง `UPDATE Matches ...` จะได้ error 229

**สิ่งที่แสดง:** `role_viewer`, การเลือก connection pool ตาม role

## ส่วนเสริมถ้ามีเวลา

1. login `manager` สมัครทีมใหม่ในฤดูกาล 2027 แล้วลองสมัครอีกทีม จะถูกจำกัดที่ 3 ทีม (`trg_Teams_LimitPerUser`)
2. login `admin` อนุมัติทีมที่ **อนุมัติทีม** (`usp_ApproveTeam`, `trg_Teams_Approved`)
3. ที่ **ฤดูกาล** เพิ่มทีมเข้าฤดูกาล 2027 แล้วกด **สร้างตารางแข่ง** (`usp_GenerateFixtures`)
